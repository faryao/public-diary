# Diary

This context describes the dated journal and how people move between reading
published entries and writing unpublished ones.

## Language

**Diary**:
The public journal and its website.
_Avoid_: Yuan’s Diary, Public Diary

**Diary entry**:
A journal record for one calendar date that is published at its own web page.
_Avoid_: GitHub page, post

**Filled date**:
A calendar date that has a published diary entry. Selecting it opens the diary
entry in a new browser tab.
_Avoid_: Written day

**Empty date**:
A calendar date that has no published diary entry. Selecting it starts a new
diary entry on GitHub.
_Avoid_: Unwritten day
